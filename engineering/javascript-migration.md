# مراجعة الشيفرة والتحويل إلى JavaScript

التاريخ: 2026-10-16. مالك المشروع والمهندس المسؤول: خالد.

## نطاق المراجعة

شمل الجرد ملفات المشروع البرمجية، مع استبعاد مكتبات الأطراف الأخرى والمخرجات المبنية والملفات المؤقتة. تحفظ قائمة الملفات الأصلية وأعداد أسطرها وبصماتها في `javascript-migration-inventory.json`. هذه مراجعة آلية للبنية والصياغة والمراجع، ومراجعة مباشرة لأدوات البناء والتوليد والاتصال والاختبارات؛ ليست ادعاء بمراجعة يدوية لكل سطر أو إثبات مصدر تأليف الشيفرة.

## التغييرات

- حُوّل 337 ملف TypeScript إلى JavaScript أو JSX باستخدام محلل لغوي، مع الحفاظ على الشيفرة التنفيذية والتعليقات والتراخيص.
- أزيلت 64 وحدة مولّدة كانت تحتوي على أنواع فقط؛ حُفظت وحدات القيم التنفيذية مثل حالات العمليات، وأُصلحت الصادرات المرتبطة بها.
- أزيلت إعدادات TypeScript القديمة وملفات البناء الوسيطة ومثال الترحيب غير المستخدم.
- حُدّثت مراجع الوحدات ونقاط الدخول إلى امتدادات JavaScript، وصحّح مولّد معاينات JSX حتى ينتج JavaScript صالحًا.
- بُسّط بناء الخادم ليجمع الوحدات المحلية، مع الاعتماد على حزم Node المثبتة بدل قائمة استثناءات لقواعد بيانات ومكتبات غير مستخدمة.
- أضيف ESLint وفحص مراجع الوحدات وتنسيق موحد. أُعيد تنظيم مؤقت رمز التحقق لتوضيح أسماء المتغيرات والتخلص من تعطيل قاعدة غير مهيأة.
- نُقلت العقود القانونية اللازمة للتشغيل من مراجع مرفقات محذوفة إلى `lib/legal-contracts`، باسترجاع نسخها من Git والتحقق من بصماتها دون تغيير محتواها المعتمد.
- أصبح توليد OpenAPI متبوعًا بتحويل المخرجات إلى JavaScript وإزالة ملفات الأنواع غير التنفيذية. إشعارات Orval تبقى ظاهرة لأن هذه الملفات مولّدة.
- أضيف سير تحقق في GitHub Actions، دون نشر أو إرسال بيانات أو تغيير قاعدة بيانات.

## اختيار اللغات

الواجهة React وJSX، والخلفية Node.js وExpress وJavaScript، وتعريفات قاعدة البيانات SQL. لا توجد حاجة وظيفية لإدخال خدمة Java أو Python في هذه الخطوة. مكتبة TypeScript تبقى اعتماد تطوير لفحص الصياغة وتحويل مخرجات OpenAPI؛ ليست لغة مصدر التطبيق.

## التحقق

- نجح فحص الصياغة ومراجع الوحدات المحلية لـ303 ملفات JavaScript، ونجح ESLint وتحقق التنسيق.
- نجحت اختبارات ترحيلات قاعدة البيانات السبعة.
- نجحت 20 مجموعة لمعالجة المستندات و10 مجموعات لإدارة الموارد و16 تحققًا لتشخيص الرسائل القصيرة، باستخدام بدائل محلية ودون طلبات مدفوعة أو اتصال بمزوّد الرسائل.
- نجح بناء الخلفية والواجهة ومساحة المعاينات محليًا على Windows.
- نجحت إعادة توليد OpenAPI وتحويله دون بقاء ملفات `.ts` أو `.tsx` في مصدر المشروع.
- تطابقت اعتماديات الحزم مع ملف القفل، وبقيت بصمات العقود القانونية الخمسة مطابقة للقيم المعتمدة.

لم تُختبر كل الرحلات التفاعلية في المتصفح أو التكامل مع قاعدة بيانات فعلية أو التخزين السحابي. ما زال تكامل التخزين الحالي مرتبطًا ببيئة ريبلت، ولم يغيّر هذا التحويل آلية المصادقة أو النماذج المستخدمة للتحليل. تحذير حجم حزمة الواجهة موجود ويحتاج إلى تحسين تحميل الصفحات عند معالجة الأداء.
