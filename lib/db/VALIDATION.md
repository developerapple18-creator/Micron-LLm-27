# التحقق من تحويل تعريفات قاعدة البيانات إلى SQL

التاريخ: 2026-10-16.

- نجحت الاختبارات السبعة في `node --test lib/db/scripts/migrate.test.mjs`، بما يشمل البصمات، وتجاوز الترحيلات المنفّذة، ورفض السجل المتقطع، ورفض التهيئة فوق جداول موجودة، والتراجع عند الخطأ، وعرض الحالة دون DDL.
- طُبّقت الترحيلات الثلاثة على محرك PostgreSQL معزول في الذاكرة باستخدام PGlite، ثم أُعيد تشغيل المنفّذ دون تنفيذ ترحيلات مكررة.
- قورنت أسماء وترتيب أعمدة الجداول الثمانية عشر مع جرد تعريفات TypeScript السابقة، وتطابقت.
- نجح `tests/constraints.sql`: العلاقات التي تتحقق من مالك القضية، وحمولة حالة التحليل، ومنع تحليلين نشطين للقضية، ورفض الأتعاب السالبة، وحماية سجلات التدقيق والقبول والمستندات المنشورة ونسخ التقارير.
- أُدخل فشل SQL متعمد في ترحيل تجريبي؛ لم يبق الجدول التجريبي أو سجل الترحيل بعد التراجع.
- نجح `git diff --check`.

لم يتم الاتصال بقاعدة بيانات المستخدم أو ترحيل بياناتها. لم يُختبر تشغيل التطبيق بالكامل أو بناء الواجهة والخلفية؛ التحقق المذكور يخص SQL وآلية الترحيلات. قاعدة PostgreSQL موجودة تحتاج إلى مقارنة مخططها قبل اعتماد سجل ترحيلات جديد، ولا يفترض هذا العمل أن مخططها مطابق للملفات.
