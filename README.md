## التحقق والبناء

يتطلب المشروع Node.js 22.17 أو أحدث ونسخة pnpm المحددة في `package.json`. تحتاج الخلفية إلى `DATABASE_URL` و`SESSION_SECRET` و`PORT`، بالإضافة إلى إعدادات الخدمات المستخدمة. تعمل واجهة التطوير على المنفذ 5173 ومسار `/` افتراضيًا، ويمكن تجاوزهما عبر `PORT` و`BASE_PATH`.

```sh
pnpm install
pnpm run check
pnpm run lint
pnpm test
pnpm run build
```

مصدر التطبيق JavaScript وJSX، وتعريفات قاعدة البيانات SQL. يستخدم فحص الشيفرة وتوليد عملاء OpenAPI مكتبة TypeScript كأداة تطوير فقط. يحوّل `pnpm --filter @workspace/api-spec run codegen` المخرجات المولّدة إلى JavaScript ويزيل وحدات الأنواع التي لا تحتوي على صادرات تنفيذية.

راجع [دليل قاعدة البيانات](lib/db/README.md) و[سجل تحويل JavaScript](engineering/javascript-migration.md) قبل تغيير مخطط البيانات أو أدوات التوليد. إعدادات البناء لا تنشئ قاعدة البيانات أو حسابات المستخدمين ولا تستدعي مزوّد الذكاء الاصطناعي.
